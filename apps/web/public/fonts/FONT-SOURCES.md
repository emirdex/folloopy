# Font sources

The reference site https://e9e.io/en was inspected on 2026-10-19. Its computed styles use Gabarito for headings and Satoshi for body/interface text.

- Satoshi Regular, Medium and Bold: Indian Type Foundry / Fontshare. Downloaded from the official Fontshare CSS distribution at https://api.fontshare.com/v2/css?f[]=satoshi@400,500,600,700&display=swap . Fontshare license: https://www.fontshare.com/licenses/itf-free-font-license . Original embedded copyright metadata is preserved.
- Gabarito Medium and SemiBold: Google Fonts distribution at https://fonts.googleapis.com/css2?family=Gabarito:wght@400;500;600;700&display=swap . SIL Open Font License included in Gabarito-OFL.txt.
- Lucide React icons: installed from the lucide-react npm package; its license is distributed in the dependency.

Fonts are served locally. The application does not fetch third-party font resources at runtime. No e9e logo, mascot, copy or proprietary artwork is included.
